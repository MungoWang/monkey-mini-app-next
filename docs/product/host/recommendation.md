# Recommendation

Layer: [Host](README.md). Index: [features.md](../features.md).

This capability is not in the product now.

A recommendation would judge more than one fact, including heat, manifest tags, and when an app is opened. Those facts are not all recorded. There is no server recommender. It is not a field of heat, and it is not a field of [Workbench](../panel/workbench.md) sources.

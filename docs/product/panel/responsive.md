# Responsive layout

Layer: [Panel](README.md). Index: [features.md](../features.md).

This capability is not in the product now.

When the panel's outer container becomes narrow, the library and its cards change layout to fit that width. The panel does not switch a dock mode to become narrow. An open app is not sent a dock position. The breakpoint and which card styles collapse are not decided. The panel has no `fill` or `side` control.

# @mini-app/shell

Role: `composition`.

The process that constructs Host. It resolves the runtime root, bootstraps or refuses config, constructs `echo` and Pi, injects the writing-skill and authoring-MCP dests, starts Host, and may open the loopback origin in the panel window. The Tauri crate is **not** in this package; it lives at [packages/launcher/tauri](../launcher/tauri). Product: [construction](../../docs/product/shell/construction.md).

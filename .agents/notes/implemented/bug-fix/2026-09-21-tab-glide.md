# Agent Note: Sliding app tab mark

Status: implemented

## Problem

The app tab rail painted the active background on the button itself. Switching tabs popped the fill instead of moving it.

## Decision

A mark under the tabs measures the active tab and slides to it. The close control stays inside the measured tab, so the mark covers it.

## Alternatives considered

- Reuse the desk switch component. That switch has no close control and a different shape. Rejected.

## Consequences

The first paint measures before the browser paints, so the mark does not flash in at the origin.
